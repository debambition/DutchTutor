I am working on a project where we want to build an agent which can help in training users who want to speak Dutch. The user should provide his profile meantioning what is native laguage, what are the difficulties they have like dislexia, etc. and what level of dutch he/she has like A1, A2, etc. Identify these levels for dutch language considering the standards. This agent should ask for any kind of details that is reqiired to cater the personalize course. It should optimize the speed from very slow to a level till the point the user is confirmatable understand and make his learning comfortable and progressive. The agent should use very small sentences and common words to start the communication. The agent should try to adapt the user level of Dutch and challenge him with a very small delta so that the learning curve is smooth rather than steep. Agent should listen to the user, correct the statement if there is any fault and then continue the conversation and keep the user engage. After every conversation the agent should keep track of the learning of the user, for example the vocablary, tenses, and other grammitical issues and continue the successive sessions from that note. The agent should always provide feedback with the topics user learned during the session and the level the user is on when the user wants to end the session.
